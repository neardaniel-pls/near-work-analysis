## [1.0.0] - 2026-05-25

### Added
- Multi-criteria analysis for 8 career roles
- 9 evaluation attributes per role (stability, visual output, work-life balance, innovation, remote-friendly, math intensity, entry difficulty, customer-facing)
- Personalized scoring with adjustable weights
- Skill gap analysis based on current proficiency
- Interactive Plotly visualizations
- Salary comparison charts
- Job compatibility scoring
- Learning effort analysis
- Strategy matrix (effort vs reward)
- Final ranking with ultimate scores
- Priority system (fit, salary, speed to hire)
